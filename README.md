# Streakfire

Track your LeetCode streak with a heatmap widget.

## Setup

### Extension
1. Go to `extension/` folder
2. Load in Chrome at `chrome://extensions/` (unpacked)

### Backend
1. `cd backend && npm install`
2. Create `.env` from `.env.example`
3. `npm run dev`

### Mobile App
1. `cd mobile-app && npm install`
2. `npm run dev`
